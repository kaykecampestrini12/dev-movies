# 🎬 Dev Movies

## 📚 Sobre o aprendizado

Este projeto foi desenvolvido durante meus estudos no curso de programação da **DevClub**, onde venho aprendendo e colocando em prática conceitos de desenvolvimento web, especialmente com **React, JavaScript, consumo de APIs e criação de interfaces**.

O projeto também foi uma oportunidade para aplicar esses conhecimentos em uma aplicação completa, desde o desenvolvimento até o deploy em produção.

Aplicação web para explorar filmes e séries, desenvolvida com React e integrada à API do TMDB.

O projeto permite visualizar conteúdos em destaque, consultar detalhes de filmes e séries, assistir a trailers e encontrar conteúdos semelhantes.

## ✨ Funcionalidades

- 🎬 Listagem de filmes em destaque
- 📺 Listagem de séries em destaque
- 🔥 Conteúdos em alta
- 🎭 Filmes por gênero
- 📖 Página de detalhes
- 🎥 Visualização de trailers
- 👥 Elenco dos filmes e séries
- 🎞️ Sugestão de conteúdos semelhantes
- 📱 Interface responsiva

- CSS
